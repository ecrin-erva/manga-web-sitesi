# maNga Web Sitesi

maNga grubu hakkında hazırlanmış tanıtım web sitesidir.

## Kullanılan Teknolojiler

- HTML5
- CSS3

## Proje Hakkında

Bu web sitesi, maNga grubunu tanıtmak amacıyla hazırlanmıştır.
Sitede grubun üyeleri, fotoğrafları ve şarkıları hakkında bilgiler yer almaktadır.

## Özellikler

- maNga grubu hakkında genel bilgiler
- Grup üyelerinin tanıtımı
- Üyelere ait fotoğraflar
- Şarkılara ulaşmak için bağlantılar
- Beyaz bordo ve siyah temalı tasarım
